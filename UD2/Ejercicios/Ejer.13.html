Sistemas gestores de contenido

Historia

Los primeros sistemas de gestión de contenidos fueron desarrollados por organizaciones que publicaron una gran cantidad de contenido en Internet y necesitban actualizaciones continuas como revistas en línea, periódicos y publicaciones corporativas.

En1995, el sitio de noticias tecnológicasCNET publicó su sistema de gestión y publicación de documentos y creó la empresa llamada Vignette, pionera de sistemas de gestión de contenidos comerciales.

La evolución de Internet hacia los portales con más contenido y el alta participación de los usuarios directamente, a través de blogs y #red sociales, convirtió los gestores de contenidos en una herramienta esencial para internet, tanto para empresas como para instituciones y personas. Los wikis sistemas y trabajo en grupo también son considerados CMS.

Actualmente hay sistemas desarrollados en software libre y propietario. En ambos casos, es necesaria una implementación para adaptar el gestor de contenidos al esquema gráfico y las funcionalidades deseadas. Para algunos gestores hay muchos modeslos disponibles que permiten una simple implementación de la parte estética por parte de un usuaio sin conocimiento de diseño. Los paradigmas de este caso son WordPress y Joomla, gestores sobre los que hay una gran comunidad de desarrolladores de extensiones (módulos, completamentos,etc.) y modelos.

Definición

Es una página web con algunas funciones de publicación. Tiene una interfaz administrativa que permite al administrador del sitio crear u organizar documentos diferentes.

El gestor de contenido es una aplicación informática utilizada para crear,editar,gestionar y publicar contenidos multimedia en varios formatos. El gerente de contenido genera páginas web dinámicas que interactúan con el servidor web para generar la página web a petición del usuario, con el formato predefinido y el contenido extraído de la base de datos del servidor.

Esto permite gestiionar, bajo un formato estandarizado, la información del servidor, reduciendo el tamaño de las páginas para la descarga y reduccción del coste de gestión del portal respeto de un sitio web estático en el que cada cambio de diseño debe realizarse en todas las páginas web, al igual que cada vez que añades contenido debes hacer una nueva página HTML y cargarla en el servidor web.

Gestión de contenido

Todo el Sistema de gestión de contenido realiza el siguiente proceso de gestión:

  • Creación de información. Es el proceso por el cual el usuaio genera nueva información para poner a disposición del público. Puede generar información como exto, gráficos, imágenes,etc.
  • Presentación de la información
  • Publicación de la información.
  • Mantenimiento de la información.-Es la actualización en la que puedes editar elimir cierto contenido.

Operación

Un sistema de gestión de contenido siempre funciona en el servidor wev, donde está hospedado el portal. El accceso al gestor generalmente se hace a través del navegador web y es necesario el uso de FTP para cargar el contenido.

Cuando un usuario accede a un URL, esa llamada se ejecuta en el servidor, se seleccionó el esquema gráfico y se ingresarán los datos correspondientes de la base de datos. La página es generada de forma dinámica para eses usuario, el código HTML final se genera en esa llamada. Normalmente, varios formatos de contenido de presentación están predefnidos en el gestor para darle flexibilidad al crear nuevas secciones e información.

Gestión de usuarios

Dependiendo de la plataforma elegida, se pueden escoger diferentes niveles de acceso para los usuarios; pasando del administrador del portal al usuario sin permiso de edición o creador de contenido. Dependiendo de la aplicación, puede haber varios permisos intermedios que permiten la edición de contenidos, el seguimiento de la republica del contenido de otros usuario,etc.

El sistema de gestión de contenidos controla y ayuda a gestionar cada etapa de este proceso, incluyendo las tareas técnicas de publicación de los documentos en uno o más sitios. En muchos sitios con estos sistemas, una sola persona desempeña el papel del creador y editor, como ejemplo en los blogs personales.
